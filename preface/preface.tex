直到最近，B样条曲线和曲面(NURBS)主要引起计算机辅助设计社区的关注，在该领域它们已成为曲线和曲面描述的标准。如今，我们看到NURBS在视觉艺术对象建模中的应用不断扩大，包括电影和娱乐行业、艺术和雕塑。NURBS现在也被用于虚拟现实应用的场景建模。这些应用预计将会增加。因此，《NURBS书籍》成为视觉传播系列专著的一部分是非常合适的。

B样条曲线和曲面在我的职业生涯中一直是一个持久的元素。1972年出版的《计算机图形学的数学元素》第一版是第一本包含B样条材料的计算机辅助设计/交互式计算机图形教材。这些材料是通过比尔·戈登和路易·纳普在锡拉丘兹大学时的好意获得的。我在1977年夏季于海军建筑师和海洋工程师协会会议上展示的一篇论文，可以说是第一篇研究B样条曲线在船舶设计中应用的论文。

对许多人来说，B样条、理性B样条和NURBS一直有些神秘。因此，在过去的几年里，迫切需要一本关于B样条和理性B样条的全面、详细、清晰易懂的书籍。因此，我怀着相当大的期待等待Les Piegl和Wayne Tiller的书籍。我没有失望:他们通过《NURBS书》优雅而充分地满足了这一需求。在为书籍开发材料时，他们利用自己在NURBS方面的丰富学术和工业经验，以直接的方式呈现这一相对复杂的主题:他们的呈现风格清晰且详细。必要的数学内容以相当关注细节和足够的严谨性呈现。算法(其中许多是类似C的伪代码)经过深思熟虑，准备得非常细致。为了准确起见，书中的每一幅插图都是计算机生成的——这是一项巨大的任务。他们创造了一本具有持久价值的书籍。

B样条曲线和曲面源于皮埃尔·贝济耶在1970年代初的开创性工作。也许可以将B样条曲线和曲面视为贝济耶曲线和曲面的“孩子”，而非均匀理性B样条(NURBS)则是“孙子”。时机恰到好处；它们无疑已经成熟。

最后，适当承认我与Les Piegl和Wayne Tiller合作使这个项目得以实现的愉悦。

非均匀有理B样条，通常称为NURBS，已成为计算机处理几何信息的表示、设计和数据交换的事实行业标准。许多国家和国际标准，如IGES、STEP和PHIGS，承认NURBS是几何设计的强大工具。NURBS取得巨大成功的原因主要在于

\begin{itemize}
\item NURBS为表示解析形状(如圆锥曲线和二次曲面)以及自由形状实体(如汽车车身和船体)提供了统一的数学基础；
\end{itemize}

\begin{itemize}
\item 使用NURBS进行设计是直观的；几乎每个工具和算法都有易于理解的几何解释；
\end{itemize}

\begin{itemize}
\item NURBS算法快速且数值稳定；
\end{itemize}

\begin{itemize}
\item NURBS曲线和曲面在常见几何变换下是不变的，例如平移、旋转、平行投影和透视投影；
\end{itemize}

\begin{itemize}
\item NURBS是非有理B样条和有理及非有理贝塞尔曲线和曲面的推广。
\end{itemize}

优秀的数学和算法特性，加上成功的工业应用，促进了NURBS的巨大普及。NURBS在CAD/CAM/CAE领域的作用类似于英语在科学和商业中的地位:“想谈生意？学会说NURBS”。

本书的目的基本上有两个:填补自七十年代初以来文献中存在的巨大空白，并提供关于NURBS各个方面的全面参考。关于NURBS的文献稀少且分散，现有论文主要涉及样条的数学，这相当复杂，需要对样条理论有详细的理解。本书旨在面向具有扎实基础的普通工程师，他们具备初级大学数学和计算的背景。理解这些概念和实现书中介绍的数百个算法并不需要博士学位。

在撰写本书的四年中，我们

\begin{itemize}
\item 调查了现有文献并呈现了重要结果；
\end{itemize}

\begin{itemize}
\item 继续我们的 NURBS 研究，并纳入了最新的发展；实际上，本书大约一半的内容是过去几年开发的新材料；x 前言
\end{itemize}

\begin{itemize}
\item 开发了一个全面的 NURBS 库，称为 Nlib V1.0、V2.0。该库是超过 20 人年 NURBS 研究和开发经验的结果，结合了我们在之前设计的系统中应用的新软件实践和经过验证的软件实践；

\begin{itemize}

几年前，一些研究人员开玩笑说 NURBS 这个缩写实际上代表的是“没有人理解有理 B 样条”。我们承认我们的同事是对的。在过去的四年里，我们在很大程度上受到这种解释的影响，并试图以直观的方式呈现书中的材料。我们希望这有助于将缩写 NURBS 改为 EURBS，即“每个人都理解有理 B 样条”。我们欢迎读者对我们的工作提出意见和可能的改进建议。
